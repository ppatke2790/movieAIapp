# Skills Needed

Roles and expertise required to take MovieAIapp from discovery through launch. Current team: **Pallavi (Designer)** — other roles TBD.

## Design (active)

| Skill | Why |
|-------|-----|
| Product / UX design | Flows, wireframes, prototyping — Pallavi |
| Visual / brand design | Cohesive movie-app aesthetic; see [brand-guidelines.md](../design/brand-guidelines.md) |
| Content design | Empty states, AI prompt hints, error copy, spoiler-safe summaries |
| Accessibility | WCAG-aware contrast, keyboard nav, screen reader labels for cards and chat |
| Interface polish (agent-assisted) | [jakubkrehel/skills](https://github.com/jakubkrehel/skills) — typography, color, layout, a11y, UX writing; see [tools-and-integrations.md](./tools-and-integrations.md) |

| Skill | Why |
|-------|-----|

| Data engineering | Movie metadata ingestion, availability sync, caching |
