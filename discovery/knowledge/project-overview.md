# Project Overview

**MovieAIapp** is a movie-focused application that uses AI to help people discover, choose, and engage with films. The repo is local-only today and will be pushed to GitHub once discovery and initial design are solid.

## What this is

A greenfield product in the **discovery phase**. There is no application code, README, or deployed environment yet. This `discovery/` folder is the single source of truth for product, design, and technical decisions until implementation begins.

## Why it exists

Streaming catalogs and recommendation engines optimize for engagement, not for helping someone actually decide what to watch tonight. MovieAIapp is being explored as an AI-native alternative: conversational, taste-aware, and focused on reducing decision fatigue rather than maximizing watch time.
