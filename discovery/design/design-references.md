# Design References

Inspiration and competitor UI patterns to study during visual design. **No Figma file or mood board links yet.**

## Patterns worth borrowing

| Product | What to study |
|---------|----------------|
| **ChatGPT / Claude** | Conversational layout, streaming responses, suggested prompts |
| **JustWatch / Reelgood** | Movie cards, availability rows, poster-forward grids |
| **Letterboxd** | Poster aesthetic, film metadata hierarchy, list density |
| **Apple TV** | Premium dark UI, hero artwork, focused detail pages |
| **Spotify** | Onboarding taste pickers, "made for you" framing |

## Visual mood (working)

- Dark shell so colorful posters pop
- Large poster art; minimal chrome
- Chat feels like texting a knowledgeable friend, not a corporate bot
- Subtle film-grain or gradient optional — avoid clutter
