# Goals & Metrics

Objectives and how success will be measured. Timeframes are provisional until launch target is set.

## North star (proposed)

**Weekly successful picks** — sessions where the user selects a recommended title and clicks through to watch or save, within one session.

## Phase 0: Discovery (now → prototype)

| Objective | Success signal | Timeframe |
|-----------|----------------|-----------|
| Align on problem and persona | PRD approved; open questions below 5 | TODO: set date |
| Validated UX concept | Clickable prototype tested with 5+ users | TODO: set date |
| Visual direction locked | Brand guidelines + key screens in Figma | TODO: set date |

## Phase 1: MVP (post-prototype)

| Objective | Metric | Target |
|-----------|--------|--------|
| Core loop works | User gets ≥3 relevant picks from one prompt | Qualitative + 70% "useful" in test |
| Speed | Time to first recommendation | < 5 seconds |
| Trust | Users report understanding *why* a pick was suggested | ≥ 4/5 in survey |
